Calendários para ler

Onde encontro o link do meu calendário?
  • Google Calendar (no computador): ⚙ Definições → escolhe o calendário à esquerda → Integrar calendário → copia o Endereço secreto no formato iCal.
  • Outlook / Microsoft 365: Definições → Calendário → Calendários partilhados → Publicar um calendário → copia o link ICS.
  • iCloud (Apple): partilha o calendário como Calendário público e copia o link (começa por webcal://).
  • Também podes pôr ficheiros .ics na pasta calendarios da app.
O link é secreto: quem o tiver consegue ver a tua agenda. Fica guardado só no teu computador.

Escrever no Google Calendar

Como obter as credenciais (só uma vez, ~5 min)
  1. Abre console.cloud.google.com e cria um projeto (ex.: «Cronometro»).
  2. Em APIs e serviços → Biblioteca, procura Google Calendar API e carrega em Ativar.
  3. Em Google Auth Platform (ecrã de consentimento OAuth): tipo Externo, nome da app e o teu email. Em Público-alvo carrega em Publicar app (se a deixares em «Teste», a ligação expira a cada 7 dias).
  4. Em Clientes → Criar cliente → tipo App para computador → transfere o ficheiro JSON.
  5. Aqui: Carregar credenciais → escolhe esse ficheiro → Ligar conta Google. O Google avisa que a app não está verificada: carrega em Avançadas → Ir para … (é a tua própria app).
A app só pede acesso aos calendários que ela própria cria: não consegue ver nem alterar o resto da tua agenda. Não juntes o calendário «Cronómetro do Dia» à lista de cima, senão os blocos aparecem em duplicado.
